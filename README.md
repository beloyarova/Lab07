Вопрос: почему ChangeName изменяет объект, видимый снаружи, а ReplaceHero не заменяет исходную переменную?

Ответ:  ChangeName меняет объект, потому что копируется ссылка, а объект остаётся один и тот же. ReplaceHero не заменяет его, потому что new Hero() записывается только в локальную копию ссылки

Вопрос: почему следующий код не компилируется?

void Print(in int value) {

 value = 10;

}

Ответ:  Не компилируется потому что in передаёт параметр как readonly-ссылку компилятор запрещает присваивать ему значение 

Шаг 2

Ответ: Обычные параметры передаются по значению метод получает копии чисел и меняет местами только их. Исходные переменные остаются прежними, а ref дает доступ к самим переменным

1. Что именно копируется при передаче параметра по значению? Объясните разницу для int и для объекта класса

Для int  само число, поэтому метод не может повлиять на исходную переменную. Для объекта класса копируется ссылка изменение полей объекта видно снаружи, но присваивание параметру нового объекта меняет только локальную копию ссылки

2. В чём разница между ref и out с точки зрения обязательной инициализации переменной до и после вызова метода?

ref требует инициализировать переменную до вызова метод может её читать и изменять. out инициализации не требует но метод обязан записать в него значение на каждом пути выполнения

3. Почему у int.TryParse используется именно out , а не ref , для параметра, куда записывается результат?

Результат создаёт сам метод, а прежнее значение переменной ему не нужно. Требовать предварительной инициализации было бы лишним

4. Какую проблему решает in ? Почему он интереснее для больших структур, чем для int ?

in передаёт параметр по ссылке, но запрещает его изменять. Для больших структур это экономит время и память не нужно копировать все поля

5. В каком порядке относительно обязательных параметров должны располагаться необязательные параметры?

После всех обязательных параметров в списке

6. В чём преимущество именованных аргументов при вызове метода с несколькими необязательными параметрами?

Можно указать только нужные параметры по имени, пропускать ненужные и менять порядок аргументов
